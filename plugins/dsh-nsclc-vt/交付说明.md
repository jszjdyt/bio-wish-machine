## 它是什么

把 [jfisher-lab/NSCLC](https://github.com/jfisher-lab/NSCLC)（Clarke et al., *Cancer Research* 2026,
doi:10.1158/0008-5472.CAN-25-2476）那套**虚拟肿瘤**算法做成了 DeepSeek Harness 插件。
算法本身不是机器学习，是**可解释的定性信号网络 + 抽象解释**：

- 162 个节点、360 条边，每个节点取整数等级 0–3，有明确的目标函数；
- 用 BioModelAnalyzer 的 **VMCAI 稳定性引擎**求稳态区间，
  即 Cook/Fisher/Krepska/Piterman, *Proving Stabilization of Biological Systems*, VMCAI 2011 的算法；
- 原版要 Windows + .NET 的 `BioCheckConsole.exe` + R 的 NANSEN 包；
  **本插件是纯 JS 逐行移植，本地直接跑，不需要任何外部依赖、不联网。**

## 四个工具

| 工具 | 干什么 |
|---|---|
| `nsclc_model` | 模型概览 + 按名字/基因符号检索节点 + 7 个已发表细胞系背景 |
| `nsclc_node` | 单节点机制卡：target function、上下游、通路证据与文献出处；给基因型还能给出稳态水平 |
| `nsclc_predict` | 跑一次模拟：表型读数、`Difference`、变化最大的节点、收敛步数 |
| `nsclc_screen` | 单药/双药筛选 + 协同排序，可导 CSV |

### 约定（重要）

- **敲除 = 钉到该节点最低等级**（本模型即 0）；`["ATM"]` 是敲除，`["MYC:3"]` 是强制激活。
- `Difference = mean(Proliferation) - mean(Death)`，**越低越好**。
- `additive = Difference(双药) - min(两个单药 Difference)`，**负 = 协同**。这就是论文 Figure 5 的定义。
- `uncertainty = (hi-lo)/跨度`，等于 0 才是被钉死在唯一取值。

### 用法举例

- 「A549 背景下同时敲 MEK 和 PI3K，虚拟肿瘤怎么说？」
- 「在 pc9、hcc827 里筛 PI3K/AKT 通路的双靶点组合，按协同排序，导出 CSV。」
- 「ATM 在模型里怎么被调控的？有文献支持吗？」
- 「我这个背景是 EGFR 突变 + p53 缺失 + CDKN2A 缺失，推荐哪些组合？」
  （→ 用 `background: "Erbb1:3,p53:0,CDKN2A:0"` 传自定义基因型）

## 照抄源码时踩到、也一并复现了的细节

这些是实现「和论文数字对得上」的关键，都写在 README 里：

1. `var(id)` 不是直接取值，而是**按读取方的范围线性重标定**，再 `trunc(x+0.5)` 取整、夹取到节点自身范围；
2. 公式里出现、但不是该节点关系边的输入，求值时按**节点下界**处理；
3. frontier 按**变量 id 从大到小**弹栈 —— 所以 `Time` 能逐位对上；
4. `-ko id level` 是**把目标函数换成常量**（永久钉住），不是初值约束；同节点多次 `-ko` 时**命令行靠前的生效**，
   所以 NANSEN 把干预写在背景前面 —— 插件同样「干预优先于背景」；
5. 空公式的节点会按 activator/inhibitor 边**合成**默认目标函数
   （无边/只有抑制 → `Const(min)`；只有激活 → `min(max, avg(pos))`；两者都有 → `max(min, avg(pos)-avg(neg))`）。

## 边界

- 结果是**定性模型上的预测**，用于排优先级、设计实验，**不是临床建议**。
- 等级 0–3 是抽象水平，不能当剂量 / IC50 / 表达量。
- 论文那条 **19 基因放疗响应 signature** 属于另一条分析链路，本插件没包含（需要的话可以再加）。
- 模型只有 162 节点 / 360 边，覆盖肿瘤内在信号通路；微环境、免疫、药代都不在里面。
